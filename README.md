**📊 Data Technician Workbook | Week 1 (Excel)**

**About This Project**

This repository contains my completed work for Week 1 of the Data Technician Programme, focusing on Microsoft Excel, data analysis, reporting, data visualisation, and data protection.

Throughout the workbook, I worked with several datasets to develop practical skills in organising, analysing, and presenting data using Excel. I also explored UK data protection legislation and gained experience using analytical tools such as Pivot Tables, Pivot Charts, formulas, and statistical calculations.

**🔒 Data Protection & Compliance**

As part of the workbook, I researched key UK regulations relating to data management and information handling, including:

Data Protection Act (DPA)
General Data Protection Regulation (GDPR)
Freedom of Information Act (FOIA)
Environmental Information Regulations (EIR)

This helped me understand the importance of protecting sensitive information, maintaining compliance, and understanding the responsibilities that organisations have when handling data.
