# 📊 Data Technician Workbook - Week 1 (Excel)

## 📖 Overview

This repository contains my completed work for **Week 1 of the Data Technician programme**, focusing on Microsoft Excel fundamentals, data protection regulations, data analysis, formulas, pivot tables, and data visualisation.

The exercises helped build practical skills used in data analysis, reporting, and business decision-making.

---

## 🎯 Learning Outcomes

### 🔒 Data Protection and Compliance

Researched and documented key UK data protection laws and regulations, including:

- 📜 Data Protection Act (DPA)
- 🌍 General Data Protection Regulation (GDPR)
- 📂 Freedom of Information Act (FOIA)
- 🌱 Environmental Information Regulations (EIR)

Key areas covered:

- ✅ The purpose of each regulation
- ✅ How organisations comply with these regulations
- ✅ The importance of protecting personal and sensitive data
- ✅ Consequences of non-compliance and data breaches
